# 摂食嚥下 正文化穴抜き1380 — 独立PWA版

`摂食嚥下認定_厳選コンパクト版.docx` を基礎データとして、全体QAのS/A判定を反映した学習アプリです。

## 収録
- 分野: 17
- 学習カード: 1,380
- 穴抜き語句: 2,365
- 元データのカードID・資料順を維持
- 全角括弧 `（ ）` 内の語句を穴抜き正答として使用
- S判定: 見出し誤カード4件を除外、誤字・語法・括弧不整合7件を修正
- A判定: MWST/フードテスト、手技、疾患の文脈欠落を本文へ補完
- A判定: 真の完全重複6件は後発側のみ除外
- 除外カードのIDは別内容へ再利用しない

## 学習モード
- 穴抜きモード: 「要復習 / 自信なし / できた」で評価し、最終問題後に学習結果を表示
- 暗記モード: 最初は穴抜き表示し、「答えを表示 / 答えを隠す」を切り替え可能
- 暗記モードは「まだ」のカードだけを次周へ残し、選択範囲がすべて「覚えた」になるまで自動周回
- 暗記セッションは途中保存・再開可能
- 暗記進捗は通常の穴抜き評価とは別データとして保存

## データ更新時の履歴
旧549カードとは問題内容を全面交換しているため、旧問題IDを新問題へ流用して学習履歴を紐付けません。
初回起動時に旧穴抜き履歴・旧暗記履歴・途中セッションを `archivedDataSets` へ退避しています。
1,390カード版から今回除外した10 IDについても、保存済み履歴を他カードへ付け替えず、そのまま保持します。
旧614→549移行時の `archivedProgress` も保持します。

## コード構成
- `index.html`: 画面構造
- `styles.css`: 画面スタイル
- `data-sections-01-05.js`: ①〜⑤の問題本文
- `data-sections-06-09.js`: ⑥〜⑨の問題本文
- `data-sections-10-13.js`: ⑩〜⑬の問題本文
- `data-sections-14-17.js`: ⑭〜⑰の問題本文
- `data.js`: メタデータ・分野情報・カード組み立て
- `data-qa-fixes.js`: S/A QA修正・除外処理。既存ID維持のためカード構築後に適用
- `core.js`: 共通学習・保存・検索・成績ロジック
- `results.js`: 穴抜きモードの結果画面
- `memory.js`: 暗記モードと周回処理
- `data-transfer.js`: JSONバックアップ / 復元
- `sw.js`: PWAオフラインキャッシュ
