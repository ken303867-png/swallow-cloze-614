# 摂食嚥下 正文化穴抜き549 — 独立PWA版

新しい「摂食嚥下認定_正文化穴抜き問題集_重複整理_出題頻度最適化版.docx」を正本として更新した学習アプリです。

## 収録
- 過去問由来コア: 519カード
- B課程カリキュラム補完: 30カード
- 合計: 549カード
- 穴抜き語句: 771個
- 重複統合: 65群
- 重複削減: 71カード

## 学習モード
- 穴抜きモード: 「要復習 / 自信なし / できた」で評価し、最終問題後に学習結果を表示
- 暗記モード: 最初は穴抜き表示し、「答えを表示 / 答えを隠す」を切り替え可能
- 暗記モードは「まだ」のカードだけを次の周へ残し、選択範囲がすべて「覚えた」になるまで自動周回
- 暗記セッションは途中保存され、「暗記モードの続き」から再開可能
- 暗記進捗は通常の穴抜き評価とは別データとして保存

## コード構成
2026-08-16に、圧縮HTMLを10分割して起動時に展開する旧構成を廃止し、役割別ファイルへ整理しました。

- `index.html`: 画面構造
- `styles.css`: 画面スタイル
- `data.js`: 549カードの問題データ
- `migration-map.js`: 旧614版から549版へのID移行表
- `core.js`: 共通学習・保存・検索・成績ロジック
- `results.js`: 穴抜きモードの結果画面・再学習処理
- `memory.js`: 暗記モードと周回処理
- `data-transfer.js`: 学習履歴のJSONバックアップ/復元
- `sw.js`: PWAオフラインキャッシュ

問題データとアプリロジックを分離したため、今後の問題更新では `data.js` と必要な移行表を中心に変更できます。

## 互換性
公開URLと既存の学習履歴を維持するため、リポジトリ名・PWA manifest ID・localStorage key は旧 `614` 名を維持しています。

- 公開フォルダ名: `swallow-cloze-614/`
- PWA manifest ID: `./swallow-cloze-614-independent-pwa`
- 学習履歴 localStorage key: `swallow_cloze_614_independent_pwa_v1`

旧614版のうち新データに対応する590カードの履歴は、初回起動時に549版へ移行します。重複統合された履歴は対応する1カードへ統合し、新資料から外れた履歴はアーカイブ領域へ保持します。
