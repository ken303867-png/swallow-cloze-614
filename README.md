# 摂食嚥下 正文化穴抜き1390 — 独立PWA版

`摂食嚥下認定_厳選コンパクト版.docx` を新しい正本として、問題データを全面交換した学習アプリです。

## 収録
- 分野: 17
- カード: 1,390
- 穴抜き語句: 2,381
- 資料順を維持
- 全角括弧 `（ ）` 内の語句を穴抜き正答として使用
- 穴抜き語句を含まない見出し・説明行はカード化しない
- 原資料の重複記載は削除せず保持
- 原資料内の括弧表記不整合2箇所は推測修正せず原文を保持

## 学習モード
- 穴抜きモード: 「要復習 / 自信なし / できた」で評価し、最終問題後に学習結果を表示
- 暗記モード: 最初は穴抜き表示し、「答えを表示 / 答えを隠す」を切り替え可能
- 暗記モードは「まだ」のカードだけを次周へ残し、選択範囲がすべて「覚えた」になるまで自動周回
- 暗記セッションは途中保存・再開可能
- 暗記進捗は通常の穴抜き評価とは別データとして保存

## データ更新時の履歴
旧549カードとは問題内容を全面交換しているため、旧問題IDを新問題へ流用して学習履歴を紐付けません。
初回起動時に旧穴抜き履歴・旧暗記履歴・途中セッションを `archivedDataSets` へ退避し、新1,390カードは未学習から開始します。
旧614→549移行時の `archivedProgress` も保持します。

## コード構成
- `index.html`: 画面構造
- `styles.css`: 画面スタイル
- `data-sections-01-05.js`: ①〜⑤の問題本文
- `data-sections-06-09.js`: ⑥〜⑨の問題本文
- `data-sections-10-13.js`: ⑩〜⑬の問題本文
- `data-sections-14-17.js`: ⑭〜⑰の問題本文
- `data.js`: メタデータ・分野情報・カード組み立て
- `core.js`: 共通学習・保存・検索・成績ロジック

- `memory.js`: 暗記モードと周回処理
- `data-transfer.js`: JSONバックアップ / 復元
- `sw.js`: PWAオフラインキャッシュ
